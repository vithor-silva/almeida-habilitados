# almeida-habilitados

Site institucional da Almeida Direção, com aulas para primeira habilitação e treinamento para condutores habilitados na Grande Florianópolis.

## Estrutura

```text
.
├── index.html
└── assets
    ├── css
    │   ├── global.css
    │   └── sections.css
    ├── images
    └── js
        └── main.js
```

O projeto é um site estático e não exige instalação de dependências. Para visualizar localmente, basta servir a pasta raiz com qualquer servidor HTTP.
